### Hi, I'm Jeeva Durai

I build [**JuzPost**](https://www.juzpost.com), an AI-first social media scheduler. Write a post once, attach images or video, and schedule or publish it to 11 networks, from the web app or by asking Claude or ChatGPT to do it for you.

**Networks:** X, LinkedIn, Instagram, Facebook, TikTok, YouTube, Threads, Bluesky, Pinterest, Tumblr, WordPress
